# Portfolio Homepage Stitch Prompt Pack

## Goal
Generate homepage UI proposals for `cyanluna.portfolio` that make project discovery more intuitive and promotional at first glance.

This portfolio already has rich project detail pages. The weak point is not lack of content, but homepage information hierarchy: too much positioning copy appears before visitors know which 2-3 projects they should open first.

## Product Context
- Repo: `cyanluna.portfolio`
- Stack: Next.js 16, React 19, Tailwind CSS 4, bilingual EN/KO
- Audience:
  - Hiring managers who want to evaluate range quickly
  - Engineering leaders who want enterprise/system proof
  - Product or ops leads who want to see practical delivery, not abstract claims
- Tone:
  - Clear, strategic, grounded
  - AI-native without sci-fi theatrics
  - Editorial and intentional, not dashboard clutter

## UX Problem To Solve
- Current homepage makes visitors read multiple narrative sections before browsing work.
- Project cards feel equal-weight even though some projects are much better entry points than others.
- The portfolio needs a guided first step:
  - `Start Here`
  - `Featured Proof`
  - `Browse All`

## Non-Negotiables
- Keep the homepage bilingual-friendly.
- Preserve the current bright-light / warm-accent visual direction.
- Avoid purple-heavy generic AI aesthetics.
- Avoid dark SaaS dashboard sameness.
- Do not design a generic masonry gallery.
- The first fold should immediately communicate:
  - AI-native problem solver
  - enterprise + AI + data product range
  - what to open first

## Content Structure To Reflect
1. Hero
2. Start Here
3. Featured Proof
4. Browse All Work

## Prompt Variant A
Design a portfolio homepage for an AI-native full-stack engineer who builds enterprise systems, AI workflows, and data-heavy products. The current problem is not missing content, but weak curation: visitors do not know what to open first. Create a homepage with a strong editorial hierarchy in this order: hero, “start here” guided entry, featured proof cards, then a browse-all project catalog. Use a bright light canvas with warm copper accents and dark typography. Make the “start here” section directional and strategic, not playful. The featured proof cards should look like high-confidence proof artifacts for hiring managers and engineering leaders. Avoid generic SaaS grids, avoid purple gradients, avoid clutter, and keep the layout readable on mobile.

## Prompt Variant B
Create a refined portfolio landing page that behaves like a curated case-study gallery rather than a flat project grid. The audience is a hiring manager or engineering leader who wants to quickly understand which 3 projects best represent enterprise systems, AI-native workflow, and data-product execution. Use a premium editorial interface with bold typography, restrained motion, and strong sectional rhythm. Include a “start here” layer with three guided entry cards, a “featured proof” row with large media-backed project cards, and a calmer browse-all grid underneath. The page should feel strategic, practical, and memorable, not like a developer template.

## Prompt Variant C
Generate a bilingual-friendly portfolio homepage UI for a technical builder whose work spans manufacturing DX, internal operating systems, AI tooling, and data visualization products. The homepage should reduce cognitive overload by separating “recommended first projects” from “all projects.” Use a clean light theme with warm industrial accents, large type, rounded cards, and strong navigation anchors. The featured section must clearly answer: why should I click this project first? Make the browse-all section filterable by strategic track and domain. Keep the design elegant and decisive, not busy.
